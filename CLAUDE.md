# MandiSaathi (FAST-NUCES FYP)

WhatsApp-only assistant for Punjab farmers: today's mandi price, short-term price forecast (F1),
where to sell after costs (F2), harvest-month outlook (F3), price alerts. Text + Urdu voice notes.
FYP-I evaluation: week of 21–23 Dec 2026 (assumption). FYP-II: Jan–May 2027.

## Data rules
- FYP-I uses **synthetic data I generate** (A1, file 03 §9): `source = SYN`, SYN and SYN-NULL
  variants, fixed seed, spec frozen at gate G2. Every reply, chart and table says "Demo data (synthetic)".
  No claim about real-market accuracy in FYP-I.
- Real data comes in FYP-II (co-supervisor export; AMIS public pages as backup). The real lockbox is
  sealed the day it arrives, before anyone looks at it.
- Never scrape Zarai Mandi. AMIS only under `docs/fetch_policy.md`; never redistribute raw AMIS data.
