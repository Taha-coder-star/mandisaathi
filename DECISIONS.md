## D-016 · 2026-11-24 · Taha · CONFIRMED
Task 3.4 evaluation harness (`mandi/models/harness.py`, `mandi/models/planted.py`, `tests/test_harness.py`), file 04 §1.3–1.4, RFC C16. Choices where the plan does not say:
- **numpy only**, no pandas/LightGBM (not dependencies yet). Row convention: `X[:, 0]` = last usable price M(t−1), feature columns after it; `y` = realised M(t+h−1) in PKR/100 kg; `dates` = issue day t. One horizon per call (filter by h first). A model is any object with `fit(X, y)` and `predict(X) -> (n, 3)` quantiles q10/q50/q90; the harness sorts them (crossing quantiles, D-010). B-N (`Naive`) is included; LightGBM (11.1) and B-SN/B-SR (7.3) plug in the same way.
- **Folds:** expanding window, 6 folds, test 3 calendar months, step 3 months, from a caller-given first test month. Train = issue day < test start − `embargo` (caller sets embargo = h−1 so no training target falls in the test window). A fold whose test window ends after `dev_end` is refused (ValueError), so rows past dev_end (the holdout year, D-014: dev ends 2025-12-18) can never enter a fold.
- **MASE scaling:** MAE of q50 ÷ MAE of B-N on the **same test rows** (out-of-sample ratio, not Hyndman's in-sample naive scale), so MASE < 1 means "beats naive on the points scored". Pooled MASE = ratio of sums over all test rows of all folds.
- **Direction accuracy:** among rows with actual |y/last − 1| > 5%, the share where sign(q50 − last) = sign(y − last); NaN if there are none. Pinball reported per quantile (0.1, 0.5, 0.9); coverage and mean width of q10..q90.
- **Bootstrap:** circular block bootstrap of the pooled MASE ratio, 2000 resamples, seeded `default_rng`, percentile 95% CI. The unit is the **day** (errors of all series on one day are summed first), block length fixed at 10 days (shortcut: no data-driven block length). `passes_s1` = pooled MASE < 1, upper bound < 1, coverage 75–85%.
- **L6 fixture:** 10 series × 1096 days from 2016-01-01, seed 34. Daily log return = 0.02·s(t−1) + 0.02·e(t), s and e iid N(0, 1), s(t−1) in X (a lead feature known on issue day t). Null twin: same draws, return = hypot(0.02, 0.02)·e(t) (pure random walk, same volatility). Reference learner = OLS of log(y/last) on the features + training-residual quantiles (dev/test only, not a candidate model). Expected planted MASE ≈ 0.02/hypot(0.02, 0.02) ≈ 0.71 with a CI half-width of about 0.02 over ~5 480 test rows, coverage ≈ 80% ± 1%, so the S1 thresholds have wide margin. The null twin must give an upper bound ≥ 1 (false-skill check, A1); by design this is a statistical test, so a fixed seed could fail it with roughly 1% chance.
- **Not done here:** no test on actual generator output: raw `syn.csv` rows carry injected defects (10× typos, swaps, per-40 kg units) that QC (5.3) and the feature builder (6.3) must handle first; the harness on SYN/SYN-NULL is task 7.3/11.1.
